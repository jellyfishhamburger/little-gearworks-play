# Kenney Nature Kit

These three GLB models are from [Kenney Nature Kit](https://kenney.nl/assets/nature-kit), released under [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/).

Files were obtained from the [Tiny Game Engine CC0 asset catalog](https://github.com/Hidencod/tge-assets/tree/main/packs/nature-kit) as tree-oak.glb, tree-default.glb, and rock-smalla.glb. Little Gearworks scales and places them at runtime.
